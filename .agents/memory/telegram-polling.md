---
name: Telegram polling
description: Ограничение Telegram long polling при переносе бота между аккаунтами.
---

Один Telegram-токен может обслуживаться только одним процессом с long polling одновременно. При запуске второго экземпляра Telegram возвращает 409 Conflict, поэтому для переноса нужно остановить старый процесс или выпустить новый токен в BotFather.

**Why:** Telegram не распределяет `getUpdates` между несколькими экземплярами одного бота.

**How to apply:** При диагностике отсутствующих ответов сначала проверь наличие второго запущенного экземпляра, а не переписывай обработчики команд.
